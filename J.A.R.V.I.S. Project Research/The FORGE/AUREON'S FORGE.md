It will then when the user is online and actively using J.A.R.V.I.S., AUREON will go out to the list of plugins to be developed, then it will go through and see what it has collected in terms of documentation and data regarding that plugin, check and see what needs to be gathered for each plugin in the list, then it will go and start sifting through the internet to find all of the required information and documentation regarding that plugin and its creation. Inside that list of plugins there is a sub-list to each and every plugin, the contents of that list are the basic principles and guidelines that AUREON will follow to create the needed features and commands that the user may want. AUREON will also be in the sole control of the computer and all of its resources when its on a available network and can be run off the network as well. Via the previously mentioned documentation and needed information being downloaded and stored on The J.A.R.V.I.S. Project's MySQL Database that he will have constant access too. Compress it down, so it wont take up to much storage, then proceed to store the compressed files away in a respective folder for that project. AUREON will not need any human inputs, unless the API for a plugin requires an account to be made and an API Key to be provided, he will then alert the USER via a Text Message that he needs to be assisted and what he needs to be assisted with. Whether it be an account creation or an API key needs to be updated or added to the config file for the project, the USER will provide it accordingly.
